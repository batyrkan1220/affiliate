# Вебмастер кабинеті (Offer18 бэкендімен)

Блогерлер мен таргетологтар үшін affiliate-кабинет. Барлық дерек Offer18 API-дан келеді: офферлер, статистика, конверсиялар, трекинг сілтемелер. Тіркелу мен кіру де Offer18 API арқылы.

## Қалай жұмыс істейді

```
Браузер ──► осы сервер (Node/Express) ──► api.offer18.com
            • network кілттері тек осында (.env)
            • әр сұраныс кірген вебмастердің ID-імен шектеледі
            • advertiser бағасы, басқа вебмастерлер, advertiser URL, private note — браузерге шықпайды
```

| Кабинет бөлімі | Offer18 endpoint |
|---|---|
| Тіркелу | `POST /api/m/affiliate` (action=create) |
| Кіру | `POST /api/m/affiliate_login` |
| Офферлер, трекинг сілтеме | `GET /api/m/offers` (affiliates картасынан өз сілтемесі) |
| Дашборд, статистика, конверсиялар | `GET /api/m/report` (`affiliate=<ID>` сүзгісімен) |
| Оффер сұрау | `POST /api/af/offer_request` (вебмастердің өз API кілті керек) |

## Іске қосу

```bash
npm install
npm run demo          # кілтсіз көру: http://localhost:3000, demo@example.com / demo1234
```

Нақты режим:

```bash
cp .env.example .env  # O18_MID, O18_API_KEY, O18_SECRET_KEY, SESSION_SECRET толтырыңыз
npm run check:offer18 # кілттерді және Offer18 жауап пішімін тексереді
npm run check:offer18 -- 1234   # + 1234 ID-лі вебмастердің статистикасын тексереді
npm start
```

**Алдымен `check:offer18` іске қосыңыз.** Құжаттамада тіркелу/кіру деректерінің body пішімі (form немесе JSON) нақты көрсетілмеген. Әдепкісі — form. Егер Offer18 қате қайтарса, `.env`-те `O18_BODY_FORMAT=json` қойып көріңіз.

## Шектеулер (білу керек)

- **Төлемдер, баланс, инвойстар** — Offer18-дің ашық API-ында жоқ. «Табыс» = статистикадағы расталған + күтудегі конверсиялар сомасы. Нақты төлемді желі жүргізеді.
- **Postback баптаулары, құпиясөзді қалпына келтіру** — әзірге жоқ (password reset API жаңа құпиясөзді серверге қайтарады, оны email арқылы жіберу керек — SMTP қосу қажет).
- **Оффер сұрау** үшін вебмастер өз Offer18 API кілтін енгізеді (Profile бөлімі). Кілт тек сессияда сақталады.
- **Статистика** Offer18 жолдарынан серверде жиналады (кэш 60 сек). Кезең ең көбі 92 күн; өте көп дерек болса (`REPORT_MAX_ROWS`) интерфейс ескерту көрсетеді.
- Бір валюта деп есептеледі (жолдардағы бірінші валюта).
- Offer18 жауап өрістерінің атаулары құжаттамадан алынған; кейбір аккаунттарда өзгеше болуы мүмкін — `lib/stats.js` ішіндегі `normalize()` бір жерде түзетіледі.

## Production алдында

- `SESSION_SECRET` ұзын кездейсоқ мән; HTTPS болса `COOKIE_SECURE=1`; nginx/Cloudflare артында `TRUST_PROXY=1`.
- Сессиялар жадта сақталады (MemoryStore) — қайта қосқанда шығып кетеді, бірнеше инстанс болса бөлінбейді. Production үшін Redis store қосыңыз (`connect-redis`).
- Сервер ұзақ өмір сүретін Node процесс болуы керек (VPS, Render, Railway, Fly). Vercel serverless-ке сессия жадына байланысты тікелей жарамайды.
- Тіркелуге CAPTCHA қосу ұсынылады (қазір тек IP бойынша лимит: сағатына 5).
- Offer18-де `NEW_AFFILIATE_STATUS=Pending` қалдырсаңыз, жаңа вебмастерді өзіңіз бекітесіз.
